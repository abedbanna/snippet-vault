# Snippet Vault

A small app to save code snippets (title + language tag + search).

## Stack
- Front end: React (in web/)
- API: NestJS (Node) (in api/)
- One repo, two apps (a monorepo).

## Conventions
- TypeScript everywhere. Small, focused commits.
- Every feature needs a test before it's "done".

## Don't
- Don't add a feature I didn't ask for.
- Don't hard-code secrets. Don't skip error handling.
