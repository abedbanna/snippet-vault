The Running Project

You'll vibe-code one small but real full-stack app — a snippet vault with a React front end and a NestJS (Node) API — and carry it through every stage. By the final module it's containerized, tested on every commit, deployed from code, and monitored. The engineering standards (Docker, CI/CD, IaC, monitoring) come straight from our DevOps Lab, so this course stays focused on coding with AI the right way rather than re-teaching the pipeline.

How This Course Works

"Vibe coding" — describing what you want and letting an AI assistant write the code — is fast and fun, but a demo that works once is not a product. Every module pairs the AI-assisted way of doing something with the DevOps standard that makes it trustworthy: version control, automated tests, code review, security gates, and repeatable deployment. Examples use Claude Code as a concrete assistant, but every principle is tool-agnostic — it applies just as well to Cursor, Copilot, or whatever you use. 100% free, no credit card required.
