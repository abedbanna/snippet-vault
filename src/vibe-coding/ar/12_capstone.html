متقدّم ختامي مشروع كامل بوتيرتك

المهمّة

بنيت خزنة المقتطفات بعجلاتٍ مساعدة — موجَّهًا، وحدةً وحدة. المشروع الختامي يزيلها. اختر فكرةً جديدةً صغيرة وخُذها من مجلدٍ فارغ إلى منتجٍ منشورٍ مُختبَرٍ مُراقَب، مطبّقًا كل ممارسةٍ من الوحدات 1–11 بنفسك.

لماذا يهمّ هذا

أيٌّ كان يستطيع اتّباع درس. أمّا شحن فكرتك أنت عبر خطّ الأنابيب الاحترافي الكامل — والذكاء الاصطناعي شريكك وDevOps انضباطك — فهو ما يُثبت المهارة. هذا المستودع هو ما تُري الناس.

اختر فكرةً صغيرة

أبقِها صغيرةً — المقصود الدورة الحياتية، لا عدد الميزات. شيءٌ فيه قليل بياناتٍ وبضعة أفعالٍ مثاليّ:

الفكرةالأفعال الأساسية
متتبّع عاداتأضِف عادة، علّم اليوم منجزًا، شاهد سلسلة.
مختصِر روابطأنشئ رابطًا قصيرًا، أعِد التوجيه، عُدّ النقرات.
سجلّ نفقاتأضِف نفقة، اعرض، رشّح بالفئة.
لوحة إشارات مرجعيةاحفظ رابطًا بوسوم، ابحث، احذف.

اقطعها أصغر ممّا يبدو صوابًا

شعرت كيف يُبقي نطاق الحدّ الأدنى المشروع قابلًا للإنهاء (الوحدة 3). طبّقه هنا بلا رحمة: ثلاث قصص مستخدمٍ تكفي. تستطيع دائمًا توسيع تطبيقٍ مشحون؛ ولا تستطيع شحن متضخّم.

قائمة الدورة الحياتية الكاملة

امشِ بفكرتك عبر الدورة كلّها. كل بندٍ يقابل وحدةً أنجزتها:

[ ] 1 Mindset: know the failure modes you're guarding against [ ] 2 Workflow: assistant set up, a context file for the new repo [ ] 3 Spec: SPEC.md — stories, acceptance criteria, milestones [ ] 4 Git: branch per milestone, review every diff [ ] 5 Build: vibe-code the milestones; take the wheel when needed [ ] 6 Tests: a test per acceptance criterion, all green [ ] 7 Quality: lint, format, validation, no secrets in code [ ] 8 Containers: Dockerfile(s) + compose; runs anywhere [ ] 9 CI: GitHub Actions runs gates on every push [ ]10 Deploy+IaC: live at a URL, infra as code [ ]11 Monitoring: /health, structured logs, a metric, an alert

هذه القائمة هي المهارة

استوعبها. كل مشروعٍ حقيقيٍّ تبنيه من الآن — بأيّ مساعد ذكاءٍ اصطناعي، بأيّ لغة — يمشي هذا المسار ذاته. ذاك ما تعنيه «البرمجة بالإحساس، بمعايير احترافية».

مختبر عملي: اشحن تطبيقك أنت

هذه الدورة كلّها، مرّةً أخرى، على فكرتك. المُسلَّم منتجٌ حقيقيٌّ مشحون مع كتابةٍ قصيرة.

ما تحتاجه

كل شيءٍ من الدورة: مساعد ذكاءٍ اصطناعي، وNode، وDocker، وحساب GitHub، ومضيف. وفكرةٌ صغيرةٌ تستخدمها فعلًا.

1

خطّط لها

مستودعٌ جديد، وملف سياق، وSPEC.md صغير (3 قصص بمعايير قبول، وقائمة مراحل). أوّل إيداع.

2

ابنِها، مُختبَرةً ونظيفة

اعمل مرحلةً مرحلةً على فروع: برمِج بالإحساس، راجع، اختبر كل معيار قبول، دقّق/تحقّق، أودِع، ادمج. أبقِ main أخضر دائمًا.

3

حوسِب وأتمِت

أضِف Dockerfile(s) + compose، وادفع إلى GitHub، واربط CI ليشغّل بواباتك عند كل دفع.

4

اشحن وراقب

انشر إلى رابطٍ عام (بنيةً ككود حيثما تستطيع)، أضِف نقطة /health، وسجلّاتٍ منظَّمة، ومقياسًا، وتنبيه تشغيلٍ واحدًا.

5

اكتبها

أنهِ REFLECTION.md ككتابةٍ قصيرة للمشروع: الفكرة، رابطك الحيّ، التقنية، أين تألّق الذكاء الاصطناعي، أين أمسكت الزمام، وأيّ ممارسة DevOps أنقذتك. هذا README معرضك.

ما الذي تسلّمه

رابطٌ لمستودعك على GitHub والتطبيق الحيّ. تحقّق من نفسك — تستطيع تعليم البنود الأحد عشر كلّها:

  • SPEC.md مُودَع؛ مراحل مبنيّة على فروعٍ بتغييراتٍ مُراجَعة
  • اختبارٌ لكل معيار قبول، ناجحٌ في CI؛ وتدقيق + تحقّق في مكانهما
  • محوسَبٌ؛ وCI أخضر عند كل دفع
  • حيٌّ على رابطٍ عام؛ /health، سجلّات، مقياس، وتنبيه
  • كتابة REFLECTION.md مع الرابط

لقد فعلتها

ما صرت تستطيعه الآن

تستطيع أخذ فكرة، ومع مساعد ذكاءٍ اصطناعي شريكًا لك، شحنها كمنتجٍ حقيقي — مواصَفةً، وخاضعةً للإصدارات، ومُختبَرةً، ومؤمَّنةً، ومحوسَبةً، ومتكامِلةً باستمرار، ومنشورةً، ومُراقَبة. تبني بالإحساس وتشحن بالانضباط. تلك مهارةٌ احترافية، وهي لك.

إلى أين بعد: وسّع مشروعك الختامي بمرحلةٍ جديدة، أو تعمّق في الجانب الهندسي في مختبر DevOps، أو ابدأ شيئًا أكبر — صار لديك الكتاب الكامل. شكرًا لبنائك معنا. الآن اذهب واشحن شيئًا.
