المشروع المتواصل

ستبرمج بالإحساس تطبيقًا صغيرًا لكنه حقيقي كامل الطبقات — خزنة مقتطفات بواجهة React وواجهة برمجية بـNestJS (Node) — وتأخذه عبر كل مرحلة. بحلول الوحدة الأخيرة يكون داخل حاوية، ومُختبَرًا عند كل إيداع، ومنشورًا من كود، ومُراقَبًا. معايير الهندسة (Docker، CI/CD، البنية التحتية ككود، المراقبة) تأتي مباشرةً من مختبر DevOps، لتبقى هذه الدورة مركّزة على البرمجة مع الذكاء الاصطناعي بالطريقة الصحيحة بدل إعادة تدريس خط الأنابيب.

كيف تعمل هذه الدورة

«البرمجة بالإحساس» — أن تصف ما تريد فيكتب المساعد الشيفرة — سريعة وممتعة، لكن عرضًا يعمل مرة واحدة ليس منتجًا. كل وحدة تقرن الطريقة المدعومة بالذكاء الاصطناعي بـمعيار DevOps الذي يجعلها جديرة بالثقة: التحكم بالإصدارات، والاختبارات الآلية، ومراجعة الشيفرة، وبوابات الأمان، والنشر القابل للتكرار. الأمثلة تستخدم Claude Code كمساعد ملموس، لكن كل مبدأ يصلح لأي أداة — ينطبق تمامًا على Cursor أو Copilot أو ما تستخدمه. مجانية 100%، بلا بطاقة ائتمان. متوفّرة أيضًا بـالإنجليزية.
